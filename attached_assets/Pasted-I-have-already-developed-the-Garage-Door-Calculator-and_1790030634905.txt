GARAGE CALCULATOR CONFIGURATION SECTION

Create a dedicated section inside Doorlink called:

Garage Calculator Configuration

This should be a proper section of the app, not just a standalone calculator page.

The section should allow users to access and configure the garage door calculator in a clean, professional and easy-to-use interface.

The flow should be:

Garage Calculator
→ Select Calculator Type
→ Enter Measurements / Specifications
→ Configure Required Options
→ Calculate
→ Display Results
→ Review / Save / Use Results

Keep it:

* Professional
* Clean
* Modern
* Easy for technicians to use
* Mobile-friendly
* Fast
* Simple to navigate
* Consistent with the existing Doorlink UI

Do NOT create an overly complicated interface.

The calculator should feel like a native Doorlink feature rather than an external website embedded into the app.

* Number fields

* mm
